# pyodide-web-compiler
# Pyodide Web Compiler & Quadratic Equation Solver

Ứng dụng web mô phỏng giao diện Visual Studio Code Dark Mode, tích hợp WebAssembly (Pyodide) để chạy và giải phương trình bậc hai trực tiếp trên trình duyệt mà không cần máy chủ backend.

## 🚀 Live Demo
👉 [Bấm vào đây để trải nghiệm ứng dụng](https://acc1khoa12345-eng.github.io/pyodide-web-compiler/)

## 🛠 Công nghệ sử dụng
- **Ngôn ngữ & Nền tảng:** Python 3.12, JavaScript (ES6+), HTML5, CSS3.
- **Engine tính toán:** WebAssembly / Pyodide (client-side execution).
- **Giao diện:** Tailwind CSS, Font Awesome, VS Code UI components.

## ✨ Tính năng chính
- Giải và biện luận phương trình bậc hai theo chuẩn IEEE 754 Floating-Point.
- Hệ thống tệp ảo giả lập môi trường VS Code.
- Đo lường và benchmark thời gian thực thi (ms).
